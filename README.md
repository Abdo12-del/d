# NG Academy — مركز مهام المساعد

تطبيق ويب عربي (RTL) يجمع كل ما يحتاجه المساعد في مكان واحد: المهام المعتادة،
المهام الخاصة، الجدول اليومي والأسبوعي، الروابط السريعة، مكتبة الرسائل الجاهزة،
ودليل التنفيذ — مع لوحة إدارة كاملة لتعديل كل المحتوى مباشرة من قاعدة البيانات.

## التشغيل

```bash
pnpm install
pnpm dev      # خادم التطوير
pnpm build    # بناء الإنتاج
pnpm preview  # معاينة نسخة الإنتاج
```

## التقنيات

- Vite + React 19 + TypeScript
- Tailwind CSS + shadcn/ui
- TanStack Query للتعامل مع البيانات
- Supabase كمصدر بيانات (يُضبط في `src/integrations/supabase/client.ts`)
- react-router-dom للتنقل

## الهوية البصرية — Assistant Command Center

هوية NG Academy الزجاجية: أزرق سماوي مشرق على خلفية فاتحة جدًا،
زجاج خفيف (`.glass`, `.card-soft`)، تدرجات ناعمة وأشكال عضوية (`.blob`)،
ظلال ناعمة (`shadow-soft`)، خط Baloo Bhaijaan 2 للعناوين فوق Cairo.
البومة 🦉 هي الشخصية المرشدة في `src/components/Owl.tsx` (بأربع وضعيات:
book / wave / cheer / point — استبدلها بالملف الأصلي عند توفره).

### فلسفة الصفحة
الواجهة نفسها هي دليل العمل: «مهمتك الآن» ثم «ماذا عليّ اليوم؟»
ثم «نظامك المعتاد» (3 مسارات: يومي/أسبوعي/شهري) ثم «شيء مختلف اليوم؟»
ثم الخط الزمني الحي، مع شريط أدوات جانبي (روابطك، Message Vault، التعليمات).
وعلى الجوال: الآن → اليوم → روتيني → خاصة → روابط، مع رصيف تنقل سفلي.

### الفصل الثلاثي الإلزامي
- 🔄 ROUTINE — المكرر (يومي/أسبوعي/شهري)
- 📅 SCHEDULED — المرتبط بوقت/يوم (الخط الزمني والجدول)
- ⭐ SPECIAL — الاستثنائي (ملصق «شيء مختلف اليوم؟»)


## البنية

```
src/
  pages/          صفحات التطبيق (المركز، المهام، الروتين، الخاصة...)
  components/
    Owl.tsx       الشخصية المرشدة (البومة)
    NowCard.tsx   بطاقة «مهمتك الآن» — بؤرة الصفحة
    TaskDrawer.tsx لوح التنفيذ الجانبي («كيف أنفذ هذه المهمة؟»)
    DayTimeline.tsx الخط الزمني الحي لليوم
    RoutineTracks.tsx مسارات الروتين الثلاثة المترابطة
    SpecialMission.tsx ملصق «شيء مختلف اليوم؟»
    RailCards.tsx  شريط الأدوات الذكي (روابطك/الرسائل/التعليمات)
    admin/        محرر الكيانات للوحة الإدارة
    layout/       الهيكل (Sidebar عضوي + رصيف الجوال)
    ui/           مكونات shadcn/ui
  lib/            الأنواع، البيانات، الذكاء (commands)، الوقت
  integrations/   عميل Supabase
```
